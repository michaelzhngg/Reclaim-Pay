  cross-origin dev resources (`/_next/webpack-hmr`, font endpoint) and the client never hydrated: every
  route stayed on the global "Loading, one moment..." overlay. Using `http://localhost:3000` fixed it.
- `qa_run` contained no policy, no webhook events and no reconciliation runs. To exercise checks 2–4 I
  added fixtures through product paths (policy upload, PayPal webhook endpoint, reconciliation seed) and
  one synthetic stuck payout row. Details are under each check.
- After the first navigation, the dev server's route manifest was stale and returned 404 for every app
  route until `frontend/app/layout.tsx` was touched (mtime only, no content change).

## Findings

1. **Medium — QA seed is incomplete.** `qa_run` had zero policies, webhook events and reconciliation
   runs. The spend-check card renders nothing without an active policy, and the webhook/reconciliation
   pages only show empty states. Checks 2–4 required fixtures to be added during the run. The seed or
   QA bootstrap should create a policy, one dead-letter event, a stuck payout and reconciliation history.
2. **Low — the dev server hangs on 127.0.0.1.** Because `allowedDevOrigins` is not set for `127.0.0.1`,
   Next blocks its dev resources, the client never hydrates, and every non-landing page stays on the
   loading overlay. Reproduce: open `http://127.0.0.1:3000/login`; open `http://localhost:3000/login`
   instead. No application code change is implied.
3. **Low — spend-check chevron inset is 12 px, not ~15 px.** Measured from the select's right edge to the
   chevron's right edge on the "What for" field. Still clearly inset; visual only.
4. **Low — maintenance toast under-reports.** "Run maintenance now" says "Checked 0 payouts and 0 events"
   when the stuck payout list contains one unrefreshable payout. The row is skipped by design, but the
   toast reads as though nothing was examined.

No application console errors or failed network requests were seen on `localhost` across the HR pages
(`/hr/dashboard`, `/hr/payouts`, webhooks, reconciliation, `/hr/review`, `/hr/contractors`, `/hr/policy`,
`/hr/settings`).
